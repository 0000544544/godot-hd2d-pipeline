# 🎓 Guide des Avantages Étudiants & Quotas Gratuits (Pipeline Zéro Euro)

Ce guide récapitule l'ensemble des accès et crédits étudiants activables pour financer et accélérer 100% de la production sans carte bancaire requise.

---

## 1. Environnement de Développement & IA de Code
| Service | Offre / Plan | Comment l'activer | Usage dans le Projet |
| :--- | :--- | :--- | :--- |
| **GitHub Student Pack** | Gratuit / Illimité | [education.github.com](https://education.github.com/pack) avec email académique (.edu ou certificat) | Débloque Copilot, crédits cloud, domaines gratuits, packs graphiques. |
| **GitHub Copilot** | 100% Gratuit pour étudiants | Inclus directement dans le GitHub Student Developer Pack | Complétion de code temps réel dans JetBrains et VS Code. |
| **JetBrains Student** | Licence Pro gratuite annuelle (renouvelable) | [jetbrains.com/community/education](https://www.jetbrains.com/community/education/students/) | IDE ultra-puissants (Rider pour Godot/C#, CLion ou IntelliJ). |
| **Google AI Studio** | Clé API Gratuite (Gemini 1.5 Pro & Flash) | [aistudio.google.com](https://aistudio.google.com/) avec compte Google | Analyse de code, refactorisation, prompts shaders dans l'extension Continue. |
